# mediamundis UX-Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. No unit-test framework; "verify" = nuxt prepare + eslint + nuxt generate + DOM/output checks. Visual sign-off is the user's (compare `npm run dev` vs `docs/demo.html`).

**Goal:** A focused UX polish pass over the implemented mediamundis site — consistent spacing rhythm, refined typography, a soft-wash text-link hover, richer micro-interactions, and premium flair (magnetic CTAs, hero parallax, variable-weight) — all reduced-motion-safe and without losing the minimalist look.

**Architecture:** Additive enhancements to existing token CSS (`app/assets/css/main.css`) and existing component scoped styles / composables. No structural rewrites.

**Tech Stack:** Nuxt 4 · Tailwind v4 (`@theme`) · @vueuse/core. Brand ease `cubic-bezier(0.2,0.7,0.2,1)`. Accent `--color-orange #F59A18`.

## Global Constraints

- **Preserve minimalism:** monochrome + single orange accent; no new colors, no 3D, no glassmorphism, no scroll-hijacking. Effects must be subtle.
- **Every animation reduced-motion-safe:** gate via the global `prefers-reduced-motion` rule and/or `useReducedMotion()`. JS pointer/scroll effects must no-op under reduced-motion and on coarse (touch) pointers where noted.
- **SSR/SSG-safe:** no `window`/`document` at module top level; client-only effects must not change SSR DOM (no hydration mismatch).
- **Use tokens:** new design values go through `@theme`/`:root` tokens (spacing scale, ease, tag bg). No new hardcoded hex except via tokens.
- **Brand ease token** `--ease-brand: cubic-bezier(0.2, 0.7, 0.2, 1)` replaces ad-hoc default `ease` on micro-interactions.
- **Don't regress** existing a11y (focus-visible, aria-hidden, contrast) or SEO.
- **Commit** after each task.

### Task P5: Magnetic hover on primary CTA + variable-weight

**Files:** Create `app/composables/useMagnetic.ts`; modify `BasePill.vue` (apply magnetic); optionally `NavLinks.vue` / `WorkRow.vue` (variable weight).

- [ ] **Create `app/composables/useMagnetic.ts`:**
```ts
import { useEventListener, useMediaQuery } from '@vueuse/core';

// Pointer-follow translate within an element. No-op on coarse pointer or reduced-motion.
export function useMagnetic(strength = 0.25) {
  const el = ref<HTMLElement | null>(null);
  const tx = ref(0);
  const ty = ref(0);
  const fine = useMediaQuery('(pointer: fine)');
  const reduced = useReducedMotion();

  useEventListener(el, 'pointermove', (e: PointerEvent) => {
    if (!fine.value || reduced.value || !el.value) return;
    const r = el.value.getBoundingClientRect();
    tx.value = (e.clientX - (r.left + r.width / 2)) * strength;
    ty.value = (e.clientY - (r.top + r.height / 2)) * strength;
  });
  useEventListener(el, 'pointerleave', () => { tx.value = 0; ty.value = 0; });

  const style = computed(() => ({
    transform: `translate(${tx.value}px, ${ty.value}px)`,
    transition: 'transform 0.2s var(--ease-brand)',
  }));
  return { el, style };
}
```
- [ ] **Apply to `BasePill`:** add `const { el, style } = useMagnetic()`; bind `:ref="el"` and `:style="style"` on the pill `<a>`. (BasePill already animates translateY(-1px) on hover — the magnetic transform will override the inline; keep the hover background change which is separate. If the -1px lift conflicts, drop the CSS translateY since magnetic provides motion.) SSR-safe: tx/ty start 0 → `translate(0,0)` identical server/client.
- [ ] **Do NOT apply magnetic to `ArrowButton`** (it uses group-hover rotate; combining transforms conflicts). Leave ArrowButton as-is.
- [ ] **Variable-weight (subtle):** add a hover weight shift on `NavLinks a` and `WorkRow h3` (e.g. `font-weight: 500 → 600` on nav; work-row h3 `600 → 680` if Archivo exposes it; otherwise nearest loaded weight 700). Use `transition: font-weight ...` (note: font-weight transitions are not universally smooth — acceptable as instant). Keep extremely subtle; skip if it causes layout shift (reserve width or use `font-variation-settings` if available).
- [ ] Verify: `nuxt prepare`, `eslint` 0, `generate`; magnetic works with mouse, no-op on touch/reduced-motion; no hydration mismatch (pill renders translate(0,0) at SSR). Commit.
